# Contributing

Thank you for improving Global Horizon Partners projects.

## Quick path

1. Search existing issues and open a focused issue for the proposed change.
2. Wait for the issue to receive the `status:approved` label.
3. Create a scoped branch and pull request that links the approved issue.

## Pull requests

Keep each pull request focused, explain the checks you ran, and describe a safe rollback. Do not include credentials, tokens, private configuration, or sensitive logs in commits, issues, or pull requests.

Use the repository's contribution instructions when they provide more specific guidance.
